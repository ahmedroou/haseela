## التقارير وأرشفة الفترات

- افتحي **التقارير ← إنشاء تقرير** لعرض الأصناف وكمياتها ومبالغها حسب التاريخ أو بين حسابين. يمكن حفظ التقرير أو مشاركته بصيغة PDF وحفظه بصيغة CSV.
- افتحي **أرشيف الفترات** لإنهاء السجل بالكامل أو حتى تاريخ أو حساب تختارينه. يمكن مراجعة الفترة المحفوظة وتصدير تقريرها أو استعادتها إلى السجل الحالي.
- حدّدي عدة منتجات من القائمة، ثم اضغطي **إضافة المحدد** لتعبئة طلب واحد أو طلبات منفصلة. ويمكن كتابة اسم منتج يدوي داخل الطلب وإضافة أسعاره عند الحاجة.
- أصبح زر حفظ الطلب وأزرار منتقي المنتجات فوق شريط تنقل Android ولوحة المفاتيح.

للتثبيت افتحي **تحديث التطبيق ← فحص التحديثات ← تنزيل وتثبيت التحديث**.
