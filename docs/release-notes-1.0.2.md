## حصيلة 1.0.2 🌸

- الرئيسية جاهزة لتسجيل الطلبات، والتقارير في تبويب مستقل.
- حسابات البريد أو الأسماء، مع النسخ السريع وملخص صغير للطلبات والقطع والحالات.
- نموذج طلب مضغوط، اختيار المنتجات المسجلة وإضافة منتجات جديدة، وآخر سعر شراء يتعبأ تلقائيًا.
- إدخال إجمالي تكلفة الكمية أو سعر الوحدة، مع حفظ إجمالي الشراء بدقة بالهللات.
- تسجيل الأرباح المستلمة: تزيد المحقق وتُخصم من المتوقع المتبقي. الوصول وحده لا يسجل استلام الربح.
- سجل قابل للتعديل والحذف للأرباح المستلمة، وسجل مضغوط لكل مبالغ الطلبات الملغية بالضغط على المفترض استرداده.
- إغلاق الحسابات وإعادة فتحها، مع بقاء بياناتها في التقرير.
- ترحيل البيانات والنسخ الاحتياطية القديمة، وتحسين ظهور النصوص والشاشات الصغيرة.

ثبّتي التحديث فوق النسخة الحالية دون حذف التطبيق للحفاظ على البيانات. يمكنك استخدام زر التحديث داخل حصيلة 1.0.1. نسخة ARM64 مناسبة لمعظم الهواتف الحديثة، وتتوفر نسخ ARMv7 وx86_64 ونسخة شاملة.
