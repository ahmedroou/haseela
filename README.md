# حصيلة 🌸

تطبيق Android شخصي لإدارة المنتجات ومجموعات الطلبات، مع تقرير موحّد يتحدّث فور الحفظ. واجهة عربية RTL، هوية وردية وليلكية، ووضع داكن بلون البرقوق. البيانات محلية بالكامل؛ الإنترنت مخصص لفحص التحديثات وتنزيلها من GitHub فقط.

[تحميل آخر إصدار](https://github.com/ahmedroou/haseela/releases/latest) · [المصدر](https://github.com/ahmedroou/haseela)

## التثبيت والاستخدام

يتطلب Android 7.0 أو أحدث. نسخة ARM64 هي الأصغر ومناسبة للهواتف الحديثة؛ النسخة الشاملة تدعم ARM64 وARMv7 وx86_64.

1. ثبّتي ملف APK وافتحي «حصيلة».
2. ستجدين «بيبي جوي كرتون رقم 4» و«بيبي جوي كرتون رقم 5»، بسعر بيع افتراضي **185 ريالًا** لكل منهما. يمكنك تعديلهما وحذفهما وإضافة أي منتجات أخرى.
3. من **الحسابات** أضيفي مجموعة، مثل «طلبات سبتمبر».
4. افتحي الحساب وأضيفي طلبًا؛ اضغطي **اختاري من قائمة المنتجات** لاختيار منتج مسجّل أو إضافة منتج جديد مباشرةً. ثم حددي الكمية وسعري الشراء والبيع.
5. غيّري الحالة من شارة الطلب مباشرة. تعرض **الرئيسية** حصيلة جميع الحسابات.

تعديل سعر المنتج لا يغيّر الطلبات السابقة. حذف المنتج يبقي الطلبات باسمها وأسعارها المسجّلة. حذف الحساب يحذف طلباته بعد تأكيد يوضح العدد والتأثير.

المنتجان الافتراضيان سجلان عاديان؛ يُضافان مرة واحدة عند إنشاء القاعدة أو ترقية النسخة القديمة، دون تغيير سعر منتج موجود بالاسم نفسه. لا يعودان عند إعادة فتح التطبيق بعد حذفهما. الأسماء الطويلة وعناوين الحقول تلتف دون اختصار، والأرقام الطويلة يصغر خطها لتظهر كاملة.

## التحديث من داخل التطبيق

ثبّتي الإصدار **1.0.1** مرة واحدة فوق الإصدار السابق دون إزالته. بعد ذلك:

1. عند فتح التطبيق أو الرجوع إليه، يفحص GitHub للإصدار الأحدث؛ أثناء الاستخدام يتكرر الفحص كل 15 دقيقة. فشل الاتصال لا يعطل التطبيق ولا يظهر تنبيهًا مزعجًا.
2. إذا توفر تحديث، تظهر بطاقة تنبيه أعلى الشاشة وعلامة على زر التحديث.
3. يمكنك الضغط على زر **تحديث التطبيق** أعلى الشاشة في أي وقت، ثم **فحص التحديثات**.
4. اضغطي **تنزيل وتثبيت التحديث**؛ يظهر التقدم ويمكن إيقاف التنزيل وإعادته.
5. أول مرة، قد يفتح Android إعداد **السماح من هذا المصدر** لحصيلة. اسمحي له ثم ارجعي لإكمال التثبيت، وأكدي **تحديث** في مثبّت Android. لا توجد حاجة إلى المتصفح أثناء هذه العملية.

الملف المناسب لمعمارية الجهاز يُختار تلقائيًا. يتحقق التطبيق من حجم التنزيل وبصمة SHA-256، ثم يتحقق Android من اسم الحزمة ورقم الإصدار وشهادة التوقيع المطابقة للنسخة المثبّتة. لا تُرفع المنتجات أو الحسابات أو الطلبات إلى GitHub. لا يوجد تثبيت صامت؛ موافقة Android مطلوبة.

## النسخ الاحتياطي

افتحي زر الضبط أعلى الشاشة الرئيسية:

- **حفظ نسخة احتياطية:** اختاري اسم ملف JSON ومكان حفظه باستخدام منتقي ملفات Android.
- **استعادة من ملف:** اختاري نسخة «حصيلة». يعرض التطبيق عدد الحسابات والمنتجات والطلبات قبل التأكيد.
- الاستعادة تستبدل البيانات الحالية ولا تدمجها. يتأكد التطبيق من صحة الملف والعلاقات والأسعار قبل تغيير أي بيانات.
- قبل كل استعادة تُحفظ نسخة أمان في مساحة التطبيق الخاصة. اختاري **استعادة آخر نسخة أمان** للعودة إلى البيانات السابقة.
- بعد الاستعادة يظهر المظهر المحفوظ في النسخة أيضًا.

قاعدة البيانات ونسخ الأمان الداخلية تبقى بعد إغلاق التطبيق وإعادة تشغيل الهاتف. إزالة التطبيق أو مسح بياناته يزيل هذه الملفات؛ احتفظي بنسخة JSON خارج التطبيق. النسخ الاحتياطية ملفات بيانات مقروءة، وليست ملفات مشفّرة.

## قواعد الأرقام

الأسعار محفوظة بالهللات كأعداد صحيحة، وتقبل الأرقام العربية والإنجليزية والفارسية، مع منزلتين عشريتين. الكمية عدد صحيح موجب. يسمح ببيع منتج بأقل من سعر شرائه وتظهر الخسارة بقيمة سالبة.

| المؤشر | ما يشمله |
|---|---|
| المنفق | شراء جميع الطلبات، حتى الملغية |
| البيع المتوقع | بيع الطلبات المنتظرة والتي وصلت |
| الربح المتوقع | فرق البيع والشراء للطلبات غير الملغية |
| الربح المحقق | فرق البيع والشراء للطلبات التي وصلت |
| قيمة الطلبات التي وصلت | إجمالي سعر بيعها |
| المفترض استرداده | تكلفة شراء الطلبات الملغية |
| الصافي بعد الاسترداد | المنفق ناقص المفترض استرداده |

عدد القطع يشمل جميع الحالات. حالة «وصل» تمثّل تحقق الربح. لا يوجد حقل للاسترداد الفعلي أو لتحصيل المبيعات.

## المصدر والبناء

التقنية: Flutter 3.41.6 / Dart 3.11.4، SQLite عبر sqflite، وإدارة حالة ChangeNotifier. الخط Tajawal مضمّن محليًا، وترخيصه في assets/fonts/OFL.txt.

- lib/domain.dart: الأنواع، مبالغ الهللات، وصحة النسخ.
- lib/database.dart: SQLite، المعاملات، التقرير، والتصدير والاستعادة.
- lib/store.dart: حالة التطبيق وتحديث التقرير بعد الحفظ.
- lib/design.dart: المظهر والحركات والأرقام المتحركة.
- lib/screens.dart وlib/forms.dart: الصفحات والنماذج والتفاعلات.
- lib/updates.dart وMainActivity.kt: فحص GitHub، تنزيل APK، والتحقق وفتح مثبّت Android.

قوائم المنتجات والحسابات والطلبات تحمّل 40 سجلًا في الدفعة وتبني البطاقات الظاهرة فقط. التقرير يجمع الأرقام داخل SQLite. إصدار قاعدة البيانات 3؛ الترحيل يضيف الفهرس والمنتجات الافتراضية دون حذف بيانات. ملف النسخة الاحتياطية بإصدار مستقل 1.

أوامر البناء والتحقق:

    flutter pub get
    flutter analyze
    flutter test --reporter expanded
    flutter build apk --release
    flutter build apk --release --split-per-abi

مفتاح الإصدار خارج المشروع في مجلد .haseela-signing داخل مجلد المستخدم؛ اسمه haseela-release.jks، وإعداداته في signing.properties.

يقرأ Gradle الإعدادات من ذلك المجلد تلقائيًا. على جهاز آخر يمكن تعيين متغير HASEELA_SIGNING_PROPERTIES إلى مسار ملف الإعدادات الخارجي. يحتوي الملف على storeFile وstorePassword وkeyAlias وkeyPassword. احتفظي بالمفتاح وإعداداته بأمان؛ استخدام المفتاح نفسه ضروري لتثبيت التحديث فوق النسخة الحالية دون إزالة التطبيق. لا تُرفع مفاتيح التوقيع إلى مستودع المصدر.

نسخة الإصدار تطلب INTERNET وREQUEST_INSTALL_PACKAGES للتحديث، ولا تطلب وصولًا شاملًا للتخزين. النسخ السحابي التلقائي ونقل بيانات التطبيق التلقائي معطّلان؛ النقل اليدوي متاح من خلال JSON.

لإصدار تحديث لاحق، ارفعي رقم النسخة والبناء في pubspec.yaml، وابني بالمفتاح نفسه، ثم انشري إصدار GitHub مستقرًا بوسم مثل v1.0.2. يجب رفع ملفات المعماريات الثلاث بأسماء haseela-1.0.2-arm64-v8a.apk وhaseela-1.0.2-armeabi-v7a.apk وhaseela-1.0.2-x86_64.apk. يقرأ التطبيق إصدار releases/latest وبصمات الملفات التي يولّدها GitHub تلقائيًا. الإصدارات المسودة والتجريبية لا تظهر كتحديثات. تفاصيل خطوات النشر في [دليل الإصدارات](docs/RELEASING.md).

الاختبارات تشمل الحسابات والكسور والخسائر، تغيير الحالات في الاتجاهين، تاريخ الطلبات، الحذف المتسلسل، استمرار البيانات بعد إعادة فتح القاعدة، الترحيل، ملفات النسخ التالفة، الاستعادة ونسخة الأمان، ونماذج الإدخال والبحث والمظهرين والشاشة الصغيرة ولوحة المفاتيح وتقليل الحركة.
